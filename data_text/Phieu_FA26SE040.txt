(*) 3.1. Capstone Project name: 
English: Develop an AI-Based Intelligent Campus Security Surveillance System for Restricted Area Access Control in Tân Uyên FPTU Campus.
Vietnamese: Xây dựng hệ thống giám sát an ninh thông minh dựa trên AI nhằm kiểm soát truy cập vào khu vực hạn chế trong khuôn viên trường đại học FPT cơ sở Tân Uyên
a. Context:
Tân Uyên FPTU campus are becoming complex, consisting of academic buildings, laboratories, data centers, research facilities, server rooms, electrical control rooms, and construction zones. Many of these areas contain valuable equipment or sensitive information and should only be accessed by authorized personnel. However, conventional security solutions primarily rely on security guards, surveillance cameras, and manual monitoring. Since operators must continuously observe multiple video streams, suspicious activities can easily be overlooked, leading to delayed responses and potential security incidents.
With the construction of the new FPT University Ho Chi Minh City campus in Tan Uyen, Binh Duong, the demand for intelligent campus security has become increasingly important. The university requires a proactive monitoring system capable of automatically identifying unauthorized access, reducing dependence on manual surveillance, and providing timely alerts to security personnel.
Recent advances in Artificial Intelligence, particularly computer vision and deep learning, enable surveillance systems to detect and recognize people in real time. By integrating AI with campus surveillance cameras and access control information, the system can identify authorized personnel, detect unknown individuals entering restricted areas, monitor access violations, and provide immediate notifications. The system can also maintain historical access records, generate security reports, and support security investigations through searchable event logs.
This project proposes the development of an AI-based intelligent campus security surveillance system that continuously monitors restricted areas, automatically detects suspicious activities, assists security staff in real-time decision-making, and improves the overall safety and operational efficiency of the FPTU HCM campus.
Functional requirement :
The system shall:
● Monitor live video streams from surveillance cameras.
● Detect human presence using AI-based computer vision.
● Identify authorized and unauthorized individuals.
● Detect unauthorized entry into restricted areas.
● Generate real-time security alerts.
● Display incident locations on a campus map.
● Record security events with timestamps and captured images.
● Allow security officers to review and validate AI detection results.
● Maintain historical surveillance logs.
● Generate daily, weekly, and monthly security reports.
● Search security incidents by person, location, or time.
● Configure restricted zones and access permissions.
Non-functional requirement:
Performance
The system shall detect unauthorized access events and generate alerts within 3 seconds after a person enters a restricted area.
Security
The system shall implement role-based access control (RBAC), secure authentication, encrypted communication, and secure storage of surveillance data to protect sensitive security information.
Reliability
The system shall provide continuous monitoring with a minimum system availability of 99.5% and ensure that surveillance events are recorded reliably even during temporary network interruptions.
 (*) 3.2. Main proposal content (including result and product)   
Proposed Solutions:
The proposed system integrates AI-powered computer vision with existing surveillance cameras to automatically monitor restricted areas within the campus. The system identifies authorized and unauthorized individuals, detects access violations in real time, generates instant alerts, records security events, and provides a centralized dashboard for campus security management. The solution supports both automated surveillance and manual verification by security personnel.
